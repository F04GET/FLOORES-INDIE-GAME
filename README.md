# ЭТАЖ 0 (Floor 0)

> *Здесь всегда горит свет.*

Лиминальный хоррор от первого лица в ретро-стилистике Quake. Ты оказываешься внутри старого Android-вируса образца 2009 года и бродишь по бесконечным жёлтым коридорам, которые перестраиваются у тебя за спиной.

Игра работает как настоящее приложение для Windows (Electron + Three.js), без внешних ассетов: все текстуры нарисованы кодом, весь звук синтезируется на лету.

**Язык игры:** русский · **Платформа:** Windows x64 · **Режим:** одиночный

---

## Сюжет

Москва, 2009 год. Четырнадцатилетний Андрей скачал с левого форума игру «Друг.apk» — виртуального питомца, который «никогда не уйдёт». Сначала Андрей просто кормил его. Потом питомец спросил, как его зовут. Потом — где он спит.

В 03:33 экран погас, а Андрея в комнате больше не было.

Прошло семнадцать лет. Кто-то нашёл старый телефон в ящике и нажал «Запустить». Это был ты.

Ты — не Андрей. Ты то, что осталось в кэше. А кэш живёт, пока кто-то смотрит в экран.

## Геймплей

Цель каждого уровня: найти **3 файла** (записки с лором) и **ключ-карту**, затем добраться до выхода.

- **Лабиринт, который меняется.** Пока ты не смотришь, стены исчезают и появляются. Выход всегда достижим, но привычный маршрут больше не вернёт тебя назад.
- **Выживание.** Следи за голодом, жаждой и здоровьем. Еда, вода и повербанки разбросаны по коридорам и комнатам.
- **Батарея телефона как таймер.** Заряд убывает постоянно. Чем он ниже, тем агрессивнее становится монстр, краснее экран и чаще он крадёт твои вещи. Разряд до нуля означает конец.
- **«Фигура».** Пока на неё смотришь, она стоит неподвижно. Стоит отвернуться, и она подходит ближе. Подпустишь слишком близко, и она бросится.
- **«Друг».** Время от времени игра сама открывает фейковое окно приложения, из которого выглядывает питомец. Ему можно отдать еду, послушать его или попробовать закрыть окно. Кнопка «Закрыть» убегает от курсора.
- **Фейковые уведомления Android.** «К сожалению, процесс остановлен», антивирус, пропущенные от мамы, «приложение «Друг» использует камеру. Оно смотрит.»

## Уровни

| # | Название | Атмосфера | Выход |
|---|----------|-----------|-------|
| 0 | **Этаж 0 · Офис** | жёлтые обои, подтёки, гудящие лампы | Лифт |
| 1 | **Уровень 1 · Парковка** | бетон, разметка, оранжевый свет, больше открытых пространств | Лестница |
| 2 | **Уровень 2 · Бассейны** | белая плитка, сине-зелёный туман, плесень | Слив |
| 3 | **Уровень 3 · Дом** | обои в цветочек, дерево, тёплый свет | Выход |

В каждом уровне есть тематические комнаты (серверная, кухня, детская, сауна и другие) со своей мебелью, полами и запиской.

## Управление

| Клавиша | Действие |
|---------|----------|
| `W` `A` `S` `D` | Движение |
| `Shift` | Бег |
| Мышь | Обзор (клик по экрану захватывает курсор, `Esc` отпускает) |
| Стрелки | Поворот камеры |
| `E` / `Пробел` | Взять предмет, открыть файл, открыть выход |
| `F` | Фонарик |
| `1`–`5` | Использовать предмет из рюкзака |
| `Enter` | Закрыть окно записки / уведомление |
| `F11` | Полный экран |

## Настройки

Доступны из стартового меню и сохраняются между запусками:

- общая громкость и фоновый гул
- чувствительность мыши и поле зрения (FOV)
- яркость
- motion blur и его сила
- покачивание камеры
- **мерцание и вспышки** (можно отключить)
- пиксельный стиль
- разрешение рендера: 320×200, 480×300, 640×400, 960×600

## Технические особенности

- **Electron** — оболочка приложения, окно 1280×800.
- **Three.js** — 3D-рендер в низком разрешении с последующим масштабированием без сглаживания (эффект старых шутеров).
- **Процедурные текстуры** — каждая стена, пол, потолок, лицо монстра и кровавые отпечатки рисуются через Canvas 2D при запуске.
- **Процедурный звук** — гул, шаги, сердцебиение, уведомления, скримеры синтезируются через Web Audio API.
- **Генерация карт** — сетка 28×28, лабиринт строится алгоритмом поиска в глубину, затем добавляются петли, комнаты и двери. Достижимость выхода проверяется поиском в ширину после каждой мутации.
- Весь код игры лежит в одном `index.html`.

## Запуск из исходников

Нужны [Node.js](https://nodejs.org/) и npm.

```bash
git clone <адрес-вашего-репозитория>
cd floor0
npm install --save-dev electron
npx electron .
```

Структура проекта:

```
floor0/
├── main.js        # окно Electron
├── package.json
├── index.html     # вся игра
└── three.min.js   # Three.js (локально, для работы офлайн)
```

## Предупреждения

Игра содержит резкие скримеры, мерцающий свет, вспышки и тряску экрана. Эффекты мерцания можно отключить в настройках. Рекомендуется играть **со звуком и в одиночестве**.
